Quote API

Use our 1,000 anonymous humor samples in your own site or app. No API key. Personal saved quotes and browser-only deletions are not shared.

Get a random quote in JavaScript

The helper downloads the public collection once and picks a quote in your app. GitHub Pages serves static files, not a server-side random endpoint.

import { getRandomQuote } from
  'https://numerate64.github.io/quotes-r-us/quote-api.js';

const quote = await getRandomQuote();
console.log(quote.text, quote.source);

Use this inside a browser script with type="module".

Server-side random endpoint

The optional Express/AWS server supports GET /api/v1/quotes/random, returning { "quote": { ... } }. Each request selects one public sample. Cross-origin reads are enabled. This endpoint is not hosted on GitHub Pages.

# After starting the Express server locally:
curl http://localhost:3000/api/v1/quotes/random
