# Sample quote collection

The 1,000 entries in `sample-quotes.json` are original AI-generated sarcastic
one-liners made for Quotes-R-Us, not authentic quotations from real people.
Every entry is labeled **Anonymous** as a fictional display attribution.

Themes include work, technology, household chores, adulting, and social life.
The collection uses themed joke patterns with different everyday situations.
Entries have unique text and stable content-derived IDs. The timestamp records
the dataset revision, not when anyone said the line.

This collection replaces the previous third-party quotation dataset in full.
No text from that dataset is included in the current samples; its source and
license remain in earlier Git history. The three offline fallback lines are
also original anonymous humor.

Samples are bundled with the site and never inserted into localStorage.
Refresh chooses from samples plus personal saved quotes. The library continues
to show only personal submissions. No third-party quote API is used at runtime.
