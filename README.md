# Quotes-R-Us

A minimal, browser-only collection of 600 humorous quotes. Pick a tag, draw a random quote, or copy one to share.

**Live site:** https://numerate64.github.io/quotes-r-us/

## Features

- Exactly 600 bundled quotes
- Random refresh without immediately repeating the current quote
- Tag filters for work, technology, adulting, social life, and everyday life
- Copy-to-clipboard action
- Keyboard shortcut: press <kbd>Space</kbd> for another quote
- Responsive, accessible static interface
- Structured GitHub Issue form for quote submissions

## Contributing

Use the [quote submission form](https://github.com/numerate64/quotes-r-us/issues/new?template=quote-submission.yml), or read [CONTRIBUTING.md](CONTRIBUTING.md) to submit a pull request.
